# Chrome 书签 AI 智能重构工作台

面向 Chrome 浏览器的书签整理与重构扩展。支持直接复用已打开的 DeepSeek / ChatGPT 网页会话（免填 API Key、零费用），也支持接入任意 OpenAI 兼容接口；所有整理建议均先进入交互式 Diff 账本与双栏目录树供人工审查和微调，确认后再安全写入 Chrome 书签。

## 核心功能

- **双引擎驱动**：默认开启**网页版会话免 API 模式**（支持 `chat.deepseek.com` 与 `chatgpt.com`），亦可一键切换为**官方/自建 API 接口直连模式**，内置小米 MiMo、DeepSeek、阿里百炼、智谱 GLM、Kimi、豆包、OpenAI、OpenRouter、Ollama 与 LM Studio 快捷预设。
- **可控的交互式审查**：支持表格勾选视图与左右双栏目录树对比视图，可按移动、改名、URL 纠偏、删除分类筛选，并可在目录树中直接内联编辑单条书签的标题、目标目录与 URL。
- **开箱即用策略库**：内置深度规范重构、自适应目录归纳、标题极简去噪、失效迁移审查与自定义专家模式五套提示词预设，支持自由编辑与持久化保存。
- **一键本地备份**：写入前可随时导出完整的 Chrome 书签树 JSON 快照。
- **Token 与成本估算**：API 模式下自动累计输入、输出与缓存命中 Token 数，支持自定义每百万 Token 单价及币种（CNY / USD）。
- **网页端双保险保底**：网页会话遇到人机验证或偶发卡顿时，支持一键直接读取网页已生成的全部轮次结果，或手动复制提示词 / 粘贴回复解析。

## 安装方式

1. 克隆或下载本仓库到本地目录：

```bash
git clone https://github.com/ccoc-cc/chrome-bookmark-ai.git
```

2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角 **开发者模式**。
3. 点击左上角 **加载已解压的扩展程序**，选择本仓库根目录即可完成安装。
4. 点击浏览器工具栏中的扩展图标，再点击 **打开独立 AI 工作台** 进入宽屏操作界面。

## 引擎配置指南

### 网页版会话免 API 模式（默认推荐）

适合不想申请或消耗 API 额度的用户，直接复用浏览器中已打开的 AI 对话页面。

1. 在工作台 **引擎配置** 页签中，确认顶部选中 **网页版会话免 API 模式**。
2. 选择要使用的网页服务卡片（**DeepSeek 网页版** 或 **ChatGPT 网页版**）。
3. 点击 **检测并打开网页会话**，浏览器会自动定位或新建对应标签页；建议在该网页中完成账号登录，避免访客模式的登录弹窗与频次限制。
4. 回到工作台点击 **探测连接状态**，卡片状态显示 **桥接就绪** 即表示连接成功。
5. 按需调整 **单批书签数**（默认 `20`，范围 `5~100`；若待整理书签在 50 条以内，可直接设为 `50` 一次性完成）与 **单批最长等待(秒)**。

### API 接口直连模式

适合书签数量较多（数百条以上）、需要稳定并发或使用本地模型（Ollama / LM Studio）的用户。

1. 在 **引擎配置** 页签切换至 **官方/自建 API 接口直连模式**。
2. 点击任意厂商快捷标签自动填入 **API Base URL** 与推荐模型，也可手动输入自定义兼容端点。
3. 填入你的 **API Key**（Ollama 等本地服务可留空），按需调整单批书签数、采样温度与 JSON 输出开关。
4. 点击 **测试接口连通性**，确认返回延时与模型名正常后，点击 **保存 API 配置**。

## 书签整理与执行流程

1. 切换到 **书签整理与审查** 页签，扩展会自动扫描当前 Chrome 书签栏。
2. 在 **分析作用域** 下拉框中选择要整理的层级（可全量扫描书签栏，也可只选某个子文件夹试跑）。
3. **强烈建议先点击【导出当前书签快照 (JSON)】**，在本地留存一份原始书签备份。
4. 点击 **开始网页会话自动化分析**（或 **开始 AI 接口分析**），工作台会按批次自动发送书签并实时将解析结果写入下方账本；分析过程中可随时点击 **停止** 中止任务。
5. 在 **交互式 Diff 变更账本** 中逐项核对结果：
   - **表格勾选确认视图**：点击顶部过滤标签（全部、仅看有变更、仅 URL 纠偏、仅移动、仅改名、仅删除）快速聚焦，通过复选框决定哪些条目生效。
   - **左右双栏目录树对比视图**：左侧展示现状目录树，右侧预览治理后的拟定目录树；支持关键词搜索、一键展开/折叠，点击条目右侧 `✏️` 按钮可直接修改标题、目标目录（支持既有目录联想，输入不存在的路径会自动创建）或 URL，亦可一键恢复原始状态。
6. 核对无误后点击 **执行选中的变更**，二次确认后扩展会将勾选条目真正写入 Chrome 书签并自动重新扫描刷新状态。

## 提示词预设与自定义模板

在 **提示词与预设** 页签可切换或微调 AI 的整理口径：

| 预设名称 | 适用场景 |
| --- | --- |
| 深度规范重构 | 同时执行标题去噪、智能归类与已知旧域名路由纠偏 |
| 自适应目录归纳 | 仅调整书签所在目录，保持原标题与 URL 不变 |
| 标题极简去噪 | 仅清理网站后缀与营销词，保持原目录与 URL 不变 |
| 失效迁移与冗余审查 | 专项排查旧域名迁移、停服归档与明显无效链接 |
| 自由专家模式 | 完全自定义 System Prompt 与 User Prompt 模板 |

自定义 **User Prompt Template** 时可使用以下两个插值变量：

- `{{FOLDER_TREE}}`：当前 Chrome 书签中已存在的目录路径列表。
- `{{BOOKMARK_LIST}}`：当前批次待处理的书签 JSON 列表（含 `id`、`title`、`url`、`current_path`）。

AI 返回结果需符合以下 JSON 结构（允许包裹在 Markdown 代码块中）：

```json
{
  "operations": [
    {
      "id": "103",
      "action": "update",
      "new_title": "Qwen",
      "new_url": "",
      "target_path": "书签栏/AI/模型",
      "reason": "保留产品正式名称并归入模型目录"
    }
  ]
}
```

字段说明：`action` 支持 `update`（修改/移动/纠偏）、`keep`（保持不变）与 `delete`（删除）；`new_title`、`new_url`、`target_path` 留空或省略表示保留原值。

## 常见问题与排障

- **网页版已经输出完 JSON，但工作台提示超时或卡在当前批次怎么办？** 直接点击工作台中的绿色按钮 **【⚡ 立即读取网页当前结果并解析】**，扩展会直接读取目标网页中已生成的全部助手回复并合并入账，无需重新让 AI 生成。
- **网页版弹出 Cloudflare 人机验证或无法自动发送怎么办？** 先在网页标签页手动完成验证或登录；也可使用工作台内的 **【📋 复制当前批次提示词】** 手动发给任意 AI 网页，生成后点击 **【📥 粘贴并解析网页回复】** 完成回填。
- **Token 费用面板怎么使用？** 网页免 API 模式下费用固定显示为 `0.0000 (免API)`；API 模式下可在面板右上角填入对应模型的每百万 Token 输入/输出/缓存单价并选择币种，实时计算本次任务预估花费。
- **哪里查看详细报错原因？** 切换到 **运行日志** 页签可查看完整的时间线日志，支持一键复制日志用于排查。

## 隐私与安全

- 所有设置、API Key 与书签快照均仅保存在本地浏览器（`chrome.storage.local`）或你主动导出的本地文件中，无任何第三方中转服务器。
- 扩展仅与你主动连接的网页标签页（`chat.deepseek.com` / `chatgpt.com`）或自行填写的 API 端点通信。
